# Emberwild Pocket

[Play Emberwild Pocket](https://dragonsdoexist.github.io/emberwild-play/)

A colorful pixel dragon sanctuary: find your first companion, raise four elemental dragons, explore together, and improve their shared home.

This repository contains only the released, self-contained game for GitHub Pages. Development sources and history are maintained separately.

## Playing and saves

Open the play link in a modern browser. No login or installation is needed. Progress is saved in this browser on this website; it is not synced between devices or transferred from other website addresses.

## Published release

Explore, Build & Battle, 1 November 2026. Adds playable egg rescues, an isometric habitat builder, friendly elemental combat, larger text and growth feedback, and a keeper tutorial.
